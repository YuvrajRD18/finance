### Question 10: Time to Double (Challenging)
**Answer: D. 12.95 years**

**Timeline:**
```
Year:    0                                              n=?
         |---------------------------------------------|
         $50,000                                       $100,000
```

**Calculation:**
- FV = PV × (1 + r)^n
- $100,000 = $50,000 × (1.055)^n
- 2 = (1.055)^n
- n = ln(2) / ln(1.055)
- n = 0.6931 / 0.0535
- n = **12.95 years**

(Rule of 72 approximation: 72/5.5 ≈ 13.09 years)

## Calculation Problems (27-29)

### Question 27: ROE and DuPont Equation Verification

**ROE Calculation:**

```
Net Income 2019 = Pre-tax earnings - Taxes = $200 - $30 = $170

Total Equity 2019 = Common Stock + Retained Earnings = $500 + $860 = $1,360

ROE = Net Income / Total Equity
ROE = $170 / $1,360 = 12.50%
```

**DuPont Equation Verification:**

```
ROE = (Net Income/Sales) × (Sales/Total Assets) × (Total Assets/Total Equity)
ROE = Net Profit Margin × Asset Turnover × Equity Multiplier

Net Profit Margin = $170 / $600 = 28.33%
Asset Turnover = $600 / $2,900 = 0.2069
Equity Multiplier = $2,900 / $1,360 = 2.132

ROE = 28.33% × 0.2069 × 2.132 = 12.50% ✓
```

**DuPont Analysis Timeline/Framework:**
```
                              ROE (12.50%)
                                   |
        ┌──────────────────────────┼──────────────────────────┐
        │                          │                          │
   Net Profit              Asset Turnover              Equity Multiplier
    Margin                                           (Financial Leverage)
   (28.33%)                   (0.2069)                    (2.132)
        │                          │                          │
   NI/Sales               Sales/TA                    TA/Equity
   $170/$600              $600/$2,900                 $2,900/$1,360
```

### Question 28: Free Cash Flow (FCF) 2019

**Timeline:**
```
                    2018                              2019
                      |                                |
                   Beginning                          End
                   Balance                          Balance
                      |                                |
                      |-------- FCF Calculation -------|
```

**Free Cash Flow Calculation:**

```
FCF = Operating Cash Flow - Capital Expenditures - Working Capital Investment

Step 1: Calculate NOPAT (Net Operating Profit After Tax)
NOPAT = EBIT × (1 - Tax Rate)
NOPAT = $230 × (1 - 0.15) = $230 × 0.85 = $195.50

Step 2: Add back Depreciation
Depreciation = $40

Step 3: Calculate Capital Expenditures (CapEx)
Using Net PPE method (more reliable):
Change in Net PPE = $2,100 - $1,740 = $360
CapEx = Change in Net PPE + Depreciation = $360 + $40 = $400

Note: The Change in Gross PPE = $4,000 - $3,600 = $400, which should equal CapEx when no assets are disposed. This confirms CapEx = $400.

Step 4: Working Capital Investment (Given)
WCInv = $150

Step 5: Calculate FCF
FCF = NOPAT + Depreciation - CapEx - WCInv
FCF = $195.50 + $40 - $400 - $150 = -$314.50

Alternative FCF Formula:
FCF = EBIT(1-t) + Depreciation - CapEx - WCInv
FCF = $230(0.85) + $40 - $400 - $150
FCF = $195.50 + $40 - $400 - $150
FCF = -$314.50

Alternative approach (using Operating Cash Flow):
Operating Cash Flow = Net Income + Depreciation = $170 + $40 = $210
FCF = Operating Cash Flow - CapEx - WCInv (ignoring changes in interest)
FCF = $210 - $400 - $150 = -$340 (approximately similar result)
```

**Answer: FCF 2019 = -$314.50** (Negative FCF indicates the company is investing heavily in growth)

### Question 29: IRR Analysis for Austin Factory Project

**Timeline (CRITICAL - Worth 5 points):**

```
        Jan 2021        End Year 1       End Year 2       End Year 3
           |               |                |                |
           ▼               ▼                ▼                ▼
     t=0              t=1              t=2              t=3
           |               |                |                |
    -$180,000         +$63,000         +$78,000         +$96,000
    (Investment)      (Cash Inflow)    (Cash Inflow)    (Cash Inflow)
```

**Cash Flow Timeline:**
```
Timeline Diagram:
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│    t=0              t=1              t=2              t=3          │
│     │                │                │                │           │
│     ▼                ▼                ▼                ▼           │
│  -180,000         +63,000         +78,000         +96,000          │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
```

**IRR Calculation Using Excel:**

In Excel, use the IRR function:
```
=IRR({-180000, 63000, 78000, 96000})
```

**Manual Calculation (Trial and Error or Financial Calculator):**

NPV = 0 = -$180,000 + $63,000/(1+IRR)^1 + $78,000/(1+IRR)^2 + $96,000/(1+IRR)^3

Testing IRR = 15%:
NPV = -180,000 + 63,000/1.15 + 78,000/1.3225 + 96,000/1.5209
NPV = -180,000 + 54,782.61 + 58,977.09 + 63,120.55
NPV = -180,000 + 176,880.25 = -$3,119.75 (Negative, IRR < 15%)

Testing IRR = 13%:
NPV = -180,000 + 63,000/1.13 + 78,000/1.2769 + 96,000/1.4429
NPV = -180,000 + 55,752.21 + 61,087.99 + 66,538.50
NPV = -180,000 + 183,378.70 = +$3,378.70 (Positive, IRR > 13%)

**IRR ≈ 13.95% (approximately 14%)**

**Decision:**
- Required Rate of Return = 15%
- Calculated IRR ≈ 14%
- Since IRR (14%) < Required Return (15%), **REJECT the project**

**Answer: Do NOT approve/accept this project because the IRR (approximately 14%) is less than the required rate of return of 15%.**
